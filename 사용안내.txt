GitHub 적용: 압축을 푼 뒤 index.html, style.css, script.js, routing.js를 저장소 최상위(main)에 업로드하여 Commit changes를 누르세요. routing.js는 신규 파일입니다. 기존 GeoJSON 3개와 logo-app.png는 유지합니다. 전체 배포 시 사용안내를 제외한 모든 파일을 올리세요.

3.3 변경 사항
- 점선 대신 모든 조사선 실선으로 표시합니다. 직접 조사 굵은 선, 2016년 연구 가는 선.
- 지도 클릭 시 화면 좌표로 가장 가까운 조사선을 찾습니다(선 중심부터 18 CSS 픽셀 이내). 경로가 겹칠 때는 가장 가까운 선이 선택됩니다.
- 출발/도착점을 지도에서 선택하거나 기존 조사선/과거 지역명 검색으로 지정합니다. 지역명은 실제 건물 입구가 아닌 조사선의 대표점입니다. 출발지는 GPS로도 정할 수 있습니다.
- 연결 그래프 및 Dijkstra 알고리즘으로 거리와 평균 경사율, 과거 데이터 여부, 검토 상태에 가중치를 부여합니다. 과거 경사 등급에는 범위 상한을 비용 계산용으로만 사용하며 실제 측정값이 아닙니다. 급경사, 비추천, 확인 필요 등 직접 조사상 추천이 아닌 경로는 기본 제외합니다.
- 조사선의 동일 좌표 및 평면 교차점을 연결한 모의 그래프입니다. 실제 교차점 통행, 계단 및 출입구 연결은 미검증입니다. 6m 이하 근사 연결은 기본 비활성화되어 있으며 선택적으로 허용할 경우 주황색으로 표시합니다. 미등록 장거리 연결은 생성하지 않습니다. 출발/도착점이 조사선에서 35m 초과 떨어져 있으면 계산하지 않습니다. 35m 이내라도 조사선까지 접근 구간을 이동 경로에 포함하지 않습니다.
- 기존 2026년 실측 자료 및 2016년 도면 판독 데이터, 사진, 제작자, 사이트 디자인은 유지했습니다. 과거 자료는 학교명이 익명 처리된 논문 Figure 3에서 추출한 근사 위치이며 전체 캠퍼스를 다루지 않습니다.
- 외부 지도 타일과 GPS 실기기 테스트는 수행하지 못했습니다. Node 알고리즘 테스트와 모의 지도 환경의 PC/모바일 브라우저 UI를 확인했습니다. 실제 이용 전 현장 검증이 필요합니다.
