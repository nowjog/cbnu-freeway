고민보다고 3.4 · 업데이트 안내

GitHub 저장소 최상위에 index.html, style.css, script.js, routing.js, external-routing.js 파일 5개를 올리고 Commit changes를 누르세요. external-routing.js는 신규 파일입니다. 기존 routes.geojson, historical.geojson, entrances.geojson, logo-app.png는 그대로 유지합니다. 전체 ZIP은 위 데이터 및 아이콘을 포함합니다.

길찾기: 조사 경로 우선 → 연결 실패 시 일반 도보 경로 보기 또는 네이버 지도 앱으로 열기. 자동 대체 경로 체크박스를 선택하면 다음 길찾기부터 외부 요청을 자동 수행합니다. 파란색은 선택한 경로 표시이며 일반 도보 경로는 경사도·계단·휠체어 접근성이 미확인입니다. 출발/도착점과 실제 경로 끝의 차이는 별도 안내하며 임의의 직선 연결을 만들지 않습니다. 주황색 점선은 설정에서 허용한 미확인 근사 연결에만 사용합니다.

네이버 공개 Directions API는 자동차 경로만 제공합니다. 도보 경로는 네이버 지도 앱 URL Scheme(/route/walk)으로 전달하며, 네이버 경로 자체를 웹사이트에 가져오는 기능은 아닙니다. PC에서는 네이버 지도 웹 링크를 열고 지점을 직접 입력하세요. 사이트 내 대체 경로: OpenStreetMap 데이터 기반 OSRM/FOSSGIS 공개 도보 서버(저빈도 학생 프로젝트용). 별도 API 키 없이 구성했으나 서버 장애, CORS, 경로 데이터 부족, 이용량 제한에 영향을 받을 수 있습니다. 외부 요청에 좌표가 전송되고 서버 로그에 기록될 수 있습니다. 앱 링크 역시 좌표를 전달합니다.
